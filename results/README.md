# Results Directory

Generated benchmark and validation outputs live here.

Tracked files:

- `README.md`
- small hand-written examples when useful

Generated files should go under:

- `raw/` for JSON/JSONL/CSV command output
- `figures/` for generated plots or text charts
- `tables/` for generated Markdown/CSV tables

Do not claim a benchmark result in reports unless its raw command output is preserved here.
