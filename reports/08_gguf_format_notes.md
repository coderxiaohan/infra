# GGUF Format Notes

InferLab implements GGUF work in two layers:

- Native parser/probe: `native_core/src/gguf.cpp`, `native_core/src/gguf_probe_main.cpp`, and `native_core/tests/gguf_test.cpp` cover metadata, tensor info, alignment, scalar previews, and many GGML quantized block formats.
- Edge Python inspector: `edge/gguf_binary_parser.py` and `edge/gguf_inspector.py` provide a lightweight binary header/metadata view for environments where building the native probe is inconvenient.

The deterministic fixture is generated by:

```bash
python3 scripts/generate_gguf_fixture.py --repo-root . --output results/raw/inferlab_fixture.gguf
./build/inferlab_gguf_probe --repo-root . --input results/raw/inferlab_fixture.gguf --output results/raw/gguf_probe.json
```

GGUF supports mmap-friendly loading because tensor metadata stores dtype, shape, and byte offsets into an aligned tensor-data region. K-quant formats trade smaller storage for block-local scale/min metadata and dequant work during matvec/decode.
